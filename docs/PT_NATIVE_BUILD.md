# Native Portuguese build

The Portuguese site under `pt/` is **hand-authored from the English masters**, not generated by the automatic translation snapshot.

## Source of truth

| Layer | Location | Notes |
| --- | --- | --- |
| Page structure, SVG drawings, IDs, CSS classes | `frontend/calculators/<slug>/index.html`, `index.html`, `frontend/about/index.html` | English master; not changed for Portuguese |
| Portuguese page content | `tools/pt_content/*.json` | Native European Portuguese copy, FAQs and exact-string maps |
| Shared calculator logic | `frontend/calculators/<slug>/<slug>.js` | Reused directly; contains no formula |
| Shared formula engine | `backend/calculations/` → `frontend/assets/js/calc-engine.js` | One implementation for every language |
| Runtime Portuguese strings | `frontend/i18n/pt/pt.json` | Source; `dict-pt.js` is generated output |

## Rebuild

```bash
python tools/rebuild_pt_dictionary.py
python tools/build_pt_native.py
python tools/audit_pt_native.py
```

`tools/build_pt_native.py` writes:

- all 24 `pt/calculators/<slug>/index.html` pages;
- `pt/index.html` and `pt/about/index.html`;
- `pt/assets/data/dashboard-data.js`.

Every generated file starts with:

```html
<!-- MW-PT-AUTHORED: hand-authored Portuguese page; do not regenerate. -->
```

`tools/build_static_languages.py` checks that marker and **skips** those files, so running the old automatic snapshot cannot overwrite them.

## Validation

```bash
cd backend && npm test
python tools/audit_pt_native.py
```

The audit checks that each Portuguese page still loads the shared calculator script, carries the authored marker, and contains no obvious English UI text.
